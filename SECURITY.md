# Security Policy

## Supported Versions

This repository is currently pre-release research code. Security fixes target the main branch.

## Reporting a Vulnerability

Do not open public issues for sensitive vulnerabilities. Contact the maintainer privately and include:

- affected files or workflow,
- reproduction steps,
- expected impact,
- any suggested mitigation.

## Model and Data Safety

This repository may process face images. Contributors should avoid committing private datasets, generated personal data, credentials, API tokens, model cache directories, or checkpoints containing non-public artifacts.
